# 📦 @cymbal/commerce-protocol

Shared TypeScript types and JSON-RPC message schemas for:
- **AP2 v0.2**: `OpenCheckoutMandate`, `ClosedCheckoutMandate`, `PaymentMandate`
- **A2A Application Messages**: `commerce.recovery.offer`, `inventory.intent.ready`
- **UCP**: Commerce session states and line-item revisions
